fadeIn

  • fadeIn(
        animationName: string,
        fadeInTime?: number,
        playTimes?: number,
        layer?: number,
        group?: string,
        fadeOutMode?: AnimationFadeOutMode,
    ): AnimationState
    • 淡入播放指定的动画。

    Parameters

    • animationName: string

      动画数据名称。

    • OptionalfadeInTime: number

      淡入时间。 [-1: 使用动画数据默认值, [0~N]: 淡入时间 (以秒为单位)] （默认: -1）

    • OptionalplayTimes: number

      播放次数。 [-1: 使用动画数据默认值, 0: 无限循环播放, [1~N]: 循环播放 N 次] （默认: -1）

    • Optionallayer: number

      混合图层，图层高的动画状态会优先获取混合权重，当混合权重分配总和超过 1.0 时，剩余的动画状态将不能再获得权重分配。 （默认: 0）

    • Optionalgroup: string

      混合组名称，该属性通常用来指定多个动画状态混合时的相互替换关系。 （默认: null）

    • OptionalfadeOutMode: AnimationFadeOutMode

      淡出模式，该属性通常用来指定多个动画状态混合时的相互替换模式。 （默认: AnimationFadeOutMode.SameLayerAndGroup）

    Returns AnimationState

    播放的动画状态。

    Example

    <pre>
        armature.animation.fadeIn("walk", 0.3, 0, 0, "normalGroup").resetToPose = false;
        armature.animation.fadeIn("attack", 0.3, 1, 0, "attackGroup").resetToPose = false;
    </pre>

    Version

    DragonBones 4.5
