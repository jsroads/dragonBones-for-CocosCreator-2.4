Function fullPathForFilename

  • fullPathForFilename(filename: string): string

  • 返回给定文件名的完整路径。

    首先，它会尝试从 "filenameLookup" 字典中获取新的文件名。 如果在字典中找不到新文件名，将使用原始文件名。 然后，它会使用 FileUtils 的搜索规则（分辨率和搜索路径）来尝试获取文件的完整路径。 文件搜索基于搜索路径和分辨率目录的数组元素顺序。

    例如： 我们通过 setSearchPaths 设置了两个元素 ("/mnt/sdcard/", "internal_dir/") 作为搜索路径， 并通过 setSearchResolutionsOrder 设置了三个元素 ("resources-ipadhd/", "resources-ipad/", "resources-iphonehd") 作为分辨率路径。 "internal_dir" 相对于 "Resources/"。 如果有一个文件名为 'sprite.png'，则文件映射字典包含 key: sprite.png -> value: sprite.pvr.gz。 首先，它会将 'sprite.png' 替换为 'sprite.pvr.gz'，然后按照以下顺序搜索文件：

    /mnt/sdcard/resources-ipadhd/sprite.pvr.gz (如果未找到，搜索下一个) /mnt/sdcard/resources-ipad/sprite.pvr.gz (如果未找到，搜索下一个) /mnt/sdcard/resources-iphonehd/sprite.pvr.gz (如果未找到，搜索下一个) /mnt/sdcard/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/resources-ipadhd/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/resources-ipad/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/resources-iphonehd/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/sprite.pvr.gz (如果未找到，返回 "sprite.png")

    如果文件名包含相对路径如 "gamescene/uilayer/sprite.png"，并且文件映射字典中包含 key: gamescene/uilayer/sprite.png -> value: gamescene/uilayer/sprite.pvr.gz， 文件搜索顺序将是：

    /mnt/sdcard/gamescene/uilayer/resources-ipadhd/sprite.pvr.gz (如果未找到，搜索下一个) /mnt/sdcard/gamescene/uilayer/resources-ipad/sprite.pvr.gz (如果未找到，搜索下一个) /mnt/sdcard/gamescene/uilayer/resources-iphonehd/sprite.pvr.gz (如果未找到，搜索下一个) /mnt/sdcard/gamescene/uilayer/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/gamescene/uilayer/resources-ipadhd/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/gamescene/uilayer/resources-ipad/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/gamescene/uilayer/resources-iphonehd/sprite.pvr.gz (如果未找到，搜索下一个) internal_dir/gamescene/uilayer/sprite.pvr.gz (如果未找到，返回 "gamescene/uilayer/sprite.png")

    如果无法在文件系统中找到新文件，它将直接返回参数中的文件名。

    该方法的添加是为了简化多平台支持。如果您使用 cocos2d-js 或任何跨平台工具链（如 StellaSDK 或 Apportable）， 可能需要在不同平台上为给定的文件加载不同的资源。
